# ⚡ me3st (metrest) - Multi-IPTV Fast Checker

**me3st** es una herramienta moderna, portátil y ultra rápida escrita en Python para comprobar múltiples listas IPTV (.m3u) simultáneamente mediante descargas y peticiones en paralelo. 

A diferencia de las herramientas web tradicionales que validan los enlaces uno por uno de forma lenta, **me3st** procesa infinitas listas al mismo tiempo aprovechando el poder de la programación asíncrona.

## 🚀 Características Únicas
- **Comprobación Masiva:** Sube todas las listas `.m3u` que quieras a la vez.
- **Ultra Velocidad:** Descargas y validaciones en paralelo (Async/Concurrent requests).
- **100% Portable:** Sin interfaces pesadas, ejecútalo en cualquier sistema con Python.
- **Resultados Limpios:** Exporta automáticamente solo los canales de IPTV que sí funcionan.

## 🛠️ Instalación y Uso

1. Clona el repositorio:
```bash
git clone https://github.com
```

2. Entra a la carpeta del proyecto:
```bash
cd me3st
```

3. Instala las dependencias necesarias:
```bash
pip install -r requirements.txt
```

4. Ejecuta la herramienta:
```bash
python me3st.py
```
